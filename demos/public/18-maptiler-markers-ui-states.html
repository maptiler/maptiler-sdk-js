UI states
H — hover: scale up + shadow
F — focus: click or Tab, green outline
A — active: press and hold, turns square/red
D — dragging: drag it, scales up + red
Priority (P marker)
hover < focus < active < dragging — combine interactions (e.g. hover + press) and the ring color shows whichever state wins.
🟡 hover · 🔵 focus · 🟠 active · 🔴 dragging
Live scale (L marker)
Base scale [1,1], hover overrides to [1.4,1.4]. Click a button while hovering: props.scale updates immediately, but the rendered transform stays masked at the hover value until you leave — then it reveals the new base. (Same mechanic applies to any settable prop, including opacity.)

Transitions (T marker)
scale, outerColor and position each ease to their new value over a configured duration/easing/delay instead of snapping — set via the transitions option or setTransitionForProperty().
